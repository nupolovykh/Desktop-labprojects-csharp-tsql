# WinForms + Database Learning

Four independent WinForms/Entity Framework exercises — not a numbered lab sequence, each folder is a standalone app.

### [`code-first-existing-db-sample/`](code-first-existing-db-sample)
EF Code-First against an existing database, using the classic Blog/Post sample.

### [`sql-table-browser/`](sql-table-browser)
First-semester WinForms + database exercise: pick any table from the connected database in a combo box and browse its rows in a grid.

### [`survey-data-manager/`](survey-data-manager)
WinForms app wired up with `Microsoft.Extensions.DependencyInjection` and EF Core, for managing geodetic survey data (projects, terrains, pickets, measurements, equipment). Entrance screen, a CRUD form, and an analytics view.

### [`materials-products-inventory/`](materials-products-inventory)
WinForms + EF Core (SQLite) app for managing materials and products, with DI-based `Forms/Services` layering.

**Tech stack:** C#, WinForms, Entity Framework
