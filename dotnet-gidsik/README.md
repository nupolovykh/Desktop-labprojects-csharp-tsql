# dotnet-gidsik

Two semesters of university C# .NET coursework.

- [`1-Semester-2023/`](1-Semester-2023) — six console-app labs: OOP fundamentals, generics, serialization, design patterns, threading. See its [README](1-Semester-2023/README.md) for the lab-by-lab index.
- [`2-Semester-2024/`](2-Semester-2024) — eight WinForms/WPF desktop labs: custom controls, EF Core, DI, MVVM, a Dropbox-backed file explorer. See its [README](2-Semester-2024/README.md) for the lab-by-lab index.

**Tech stack:** C#, .NET 6.0, WinForms, WPF, EF Core, xUnit
