# lab4 — Materials/Products CRUD (WPF)

One project: `Lab4` — WPF, EF Core (SQLite).

The WPF rebuild of [`lab3/`](../lab3)'s Materials/Products domain: `MainWindow` plus dedicated grid windows (`MaterialsGrid`, `ProductsGrid`, `OneGrid`) and custom edit windows (`MaterialsCustom`, `ProductsCustom`), backed by XAML `UserControl`s (`CustomControls/MaterialView`, `CustomControls/ProductView`) instead of WinForms controls.

**Tech stack:** C#, .NET 6.0, WPF, EF Core, SQLite
